How It Works

Four steps from zero to a live API response

01

Connect Wallet

Connect via any EVM-compatible wallet. Your wallet address acts as your identity. Upon connecting, a Circle Programmable Wallet is provisioned for you.

02

Generate API Key

Go to the API page and sign with your wallet for ownership verification to generate a key tied to your wallet address. The key is displayed only once.

03

Call /run

POST to /run using an Authorization: nvq_… header. Provide a service_id and your input_data. The backend authenticates your key.

04

Pay & Receive Result

A USDC micro-transfer is executed on the Arc. Once the transaction is confirmed on-chain, the requested service runs and returns the JSON result.

import requests

response = requests.post("https://YOUR_DOMAIN/run",
    headers={"Authorization": "nvq_YOUR_API_KEY"},
    json={
        "service_id": "token_price",
        "input_data": "bitcoin"
})
print(response.json()["result"])
const response = await fetch("https://YOUR_DOMAIN/run", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "Authorization": "nvq_YOUR_API_KEY"
    },
    body: JSON.stringify({
        "service_id": "token_price",
        "input_data": "bitcoin"
    })
});
const data = await response.json();
console.log(data.result);
