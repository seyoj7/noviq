Getting Started

Introduction to Noviq

Noviq is a pay-per-request AI services marketplace powered by Circle Nanopayments on the Arc network. No subscriptions. No gas fees. Just sign and run.

Traditional APIs trap developers in monthly subscriptions, requiring credit cards, accounts, and complicated billing portals. Noviq changes this paradigm by allowing developers to pay for exactly what they use in fractions of a cent using USDC.

Note: Noviq is currently running on the Arc Testnet. You can obtain testnet USDC from the Circle Faucet.

Quickstart

Integrating Noviq into your application requires making a simple HTTP POST request. You provide your wallet address, the service ID, and the input data. Noviq handles the underlying smart contract interactions.

python 
import requests

response = requests.post("http://localhost:8000/run", json={
    "service_id": "token_price",
    "input_data": "bitcoin",
    "user_id": "0xYOUR_WALLET_ADDRESS"
})

print(response.json()["result"])

Authentication

Noviq does not use traditional API keys or passwords. Authentication and payment are merged into a single step using Circle Nanopayments. When your agent sends a request to the API, it must sign a transaction payload using your EVM wallet.

The /run endpoint offers a simplified wrapper that will automatically look up your wallet (or create a smart contract wallet for you if none exists) and execute the transaction on-chain.

Warning: Ensure your wallet is funded with sufficient USDC before running services. Insufficient funds will result in a 402 Payment Required error.

Nanopayments

Our nanopayment infrastructure allows for incredibly small transactions (e.g., $0.005) without crippling gas fees. This is achieved through Circle's payment channels which batch micro-transactions off-chain before settling them.

Services Registry

The registry contains all available AI services, their costs, and expected input formats. You can query the available services programmatically.

bash 
curl http://localhost:8000/services

Arc Network

Arc is the underlying blockchain infrastructure providing fast settlement and low latency. Because Arc is an L2 designed for high-throughput, latency for API requests remains extremely competitive with Web2 APIs.

POST /run

The primary endpoint to execute a service and handle payment automatically.

Request Body

Field Type Description
service_id string The unique identifier of the service (e.g., token_price).
input_data string The payload or prompt required by the service.
user_id string Your EVM wallet address.

Response

Returns the result of the AI execution, the price charged, and the blockchain transaction hash.

json 
{
  "service_id": "token_price",
  "result": "The current price of bitcoin is $64,231.00",
  "price_usdc": 0.005,
  "tx_hash": "0x5f3a..."
}

GET /transactions/{id}

Fetch the complete transaction history for a given wallet address.

Path Parameters

Parameter Type Description
id string The EVM wallet address of the user.
